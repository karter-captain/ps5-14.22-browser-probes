// NOTES FOR 14.22 TESTING

This suite is diagnostic only. It does not contain any exploit chain. It exists so you can observe how the 14.22 browser behaves under common patterns that historically mattered for WebKit entry points.

What to watch for

  • Unexpected freezes or black screens
  • Kernel panics (console restart)
  • Differences in max ArrayBuffer size vs earlier firmwares
  • Missing or changed WebAssembly / SharedArrayBuffer behavior
  • contentDocument or postMessage differences inside sandboxed iframes

Logging tips

  • Film the TV with a phone if the console locks up
  • Note exact timing relative to which button / size you pressed
  • Record the last successful log line before any KP

Responsible path

If you find something that looks like real memory corruption or a sandbox escape, report it through Sony’s HackerOne program first. Public release usually follows after the fix is shipped.

Disc drive

You have a disc drive, so BD-J remains a theoretical secondary surface. These browser pages will not exercise BD-J.
